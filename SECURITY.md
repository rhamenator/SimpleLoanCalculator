# Security policy

## Supported versions

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is available. Otherwise, email `rich@yourfoxprodeveloper.com` with the repository name, affected version or commit, reproduction steps, and potential impact.

Do not include credentials, personal financial information, or other sensitive data in a public issue. You should receive an acknowledgement within seven days.

## Security boundaries

Exact Loan Calculator is an offline calculation tool. It does not connect to lenders, retrieve market rates, convert currencies, store accounts, or transmit calculations. Clipboard export is performed only when the user explicitly selects **Copy schedule**.

Results are estimates and must not be treated as lender disclosures or professional financial advice.
