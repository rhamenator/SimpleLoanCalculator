# Application icon

The calculator with a descending loan-balance motif was generated with the built-in image generation tool and selected by the maintainer on October 22, 2026.

Source: `assets/exact-loan-calculator-icon-source.png` (transparent PNG). Windows assets are derived by cropping the transparent margin, preserving aspect ratio and alpha, and centering the image on each existing asset canvas. Square PNGs use an 86% fit, wide/splash canvases 76%; the multi-resolution ICO uses a 92% fit and 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel entries. Resampling uses Pillow Lanczos. Existing asset filenames and manifest references are retained.

## Generation prompt

Use case: logo-brand. Asset type: a single Windows desktop application icon concept for Exact Loan Calculator (repository SimpleLoanCalculator). Create one polished, distinctive, small-size-legible Fluent-style app icon: a compact calculator silhouette with a clear display and a few large keys, integrated subtly with a short amortization stair-step motif suggesting a loan balance decreasing to zero. Strong simple silhouette, restrained depth, crisp generous shapes and spacing, no tiny detail, no text or letters, no currency symbol, no badge, no surrounding presentation board, no device mockup. One centered icon, straight-on view, comfortably padded within a square canvas, genuinely transparent outer background. This is a design concept for review, not an instruction to replace the current application assets.
